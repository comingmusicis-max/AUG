## จุดที่ตีความไว้ — ตรวจก่อนสั่ง build

1. **ซีน 7 ยังไม่มีรูป** brief ให้มาเป็นลิงก์โพสต์ Facebook 3 อัน ไม่ใช่ไฟล์รูป
   (`facebook.com/photo.php?fbid=...`) โหลดอัตโนมัติไม่ได้ ตอนนี้ซีน 7 มีแต่คลิป `C2241`
   **ส่งไฟล์ JPG มา 3 รูป แล้วจะแทรกให้เป็นภาพนิ่งก่อน `C2241`**
   (ลิงก์อันที่สองมีตัว "ง" ติดท้าย URL มาด้วย — น่าจะพิมพ์เกิน)
2. **เคสที่สองในเอกสารยังทำไม่ได้** `โปรแกรมไหมน้ำใต้ตา` (7 ซีน) เขียนรายละเอียดกับ Text มาครบ
   แต่**ไม่มีลิงก์ไฟล์สักอันเดียว** เลยยังไม่ได้ทำเป็น job แยก ส่งลิงก์มาเมื่อไหร่ทำต่อได้ทันที
3. **ซีน 3, 4, 5 mute ฟุตเทจ** เพราะช่อง Voice-over มีไฟล์เสียงมาแทน (`C2236`, `C2237`, `C2239`)
   ถ้าอยากได้เสียงบรรยากาศกลับมา ลบ `"mute": true` ออกได้
4. **ซีน 1, 6, 7 ไม่ mute** ช่อง Voice-over ว่าง เลยใช้เสียงอินฟลูในคลิป
5. **ค้างรูป 2.0 วิ เป็นค่าตั้งเอง** ซีน 2 ไม่มี VO เลยตั้งเอง / ซีน 3 มี VO — รัน
   `fit_stills.py` แล้วมันจะยืดสองรูปให้พอดีความยาว `C2236` ให้เอง
6. **ซีน 2 ยังไม่ได้ทำลูกศร** brief สั่ง "ประกบกัน และทำลูกศรชี้หน้า ก่อนทำดูหน้าย้วย" — ทำมือ
7. **ไม่มีจุดตัดมาสักซีน** ทุกคลิปวางเต็มความยาว ซีน 6 มี 4 คลิปรวด น่าจะยาวสุด
   ดูตัวเลขที่ `build_draft.py` พิมพ์ ถ้าเกิน 60 วิ ตัดที่ซีน 6 ก่อน

## วิธีรัน (บนเครื่อง Windows ที่มี CapCut)

```bat
set S=.claude\skills\capcut-edit-builder\scripts
set J=jobs\theface-13-07-69\plan

python %S%\fetch_media.py %J%\media.json
python %S%\match_grade.py D:\ClinicVideo\theface-13-07-69 --preview
python %S%\match_grade.py D:\ClinicVideo\theface-13-07-69 --write
python %S%\fit_stills.py %J%\edit_plan.json --write
python %S%\build_draft.py %J%\edit_plan.json
```

`edit_plan.json` ชี้ `media_dir` ไปที่โฟลเดอร์ `graded` แล้ว — ถ้าไม่อยากเกรดสี
ตัดคำว่า `/graded` ออกจากบรรทัด `media_dir` แล้วข้ามสองคำสั่ง `match_grade` ไป

ปิด CapCut ก่อนรัน `build_draft.py` และต้องเคยเซฟโปรเจกต์เปล่าใน CapCut ไว้อย่างน้อย 1 อัน

**การที่ JSON ผ่านไม่ได้แปลว่าโปรเจกต์เปิดได้** ตัวตัดสินจริงคือเปิด CapCut แล้วเห็นไทม์ไลน์ครบ
